### Округление чисел: ROUND, FLOOR, CEILING

Функция `ROUND(число, [знаков_после_запятой])` округляет число до заданного количества знаков после запятой (по умолчанию — до целого, если второй аргумент не указан):

```sql
SELECT ROUND(1234.5678, 2) AS rounded;
-- вернёт 1234.57
```

```sql
SELECT ROUND(1234.5678) AS rounded_to_int;
-- вернёт 1235 (округление по правилам "к ближайшему")
```

`ROUND` умеет и округлять до десятков, сотен и так далее — для этого нужно передать **отрицательное** число знаков:

```sql
SELECT ROUND(1234.5678, -2) AS rounded_to_hundreds;
-- вернёт 1200
```

`FLOOR` округляет число **вниз**, до ближайшего целого, не превышающего исходное значение, независимо от того, насколько близко исходное число к следующему целому:

```sql
SELECT FLOOR(4.99) AS floored;
-- вернёт 4
```

`CEILING` (синоним — `CEIL`), наоборот, округляет **вверх**, до ближайшего целого, не меньшего исходного значения:

```sql
SELECT CEILING(4.01) AS ceiled;
-- вернёт 5
```

Разница между `ROUND`, `FLOOR` и `CEILING` часто важна в бизнес-логике: например, при расчёте количества упаковок, которые нужно заказать, чтобы вместить определённое количество товара, логичнее использовать `CEILING` (упаковки нельзя заказать «дробно» — если нужно 4.2 упаковки, реально придётся заказать 5), а не `ROUND`, который округлил бы 4.2 до 4 и не хватило бы места для товара.

### ABS: абсолютное значение

Функция `ABS` возвращает модуль числа — то есть само число, если оно положительное, и число без знака минус, если оно отрицательное:

```sql
SELECT ABS(-42) AS abs_value;
-- вернёт 42
```

Практическое применение — например, при сравнении отклонения фактического остатка на складе от плана, когда важна сама величина разницы, а не то, в какую сторону она направлена:

```sql
SELECT name, stock, ABS(stock - 20) AS deviation_from_plan
FROM products;
```

### NOW: текущая дата и время

Функция `NOW()` возвращает текущую дату и время на момент выполнения запроса, в формате `DATETIME`:

```sql
SELECT NOW();
-- например, вернёт '2024-06-15 14:32:07'
```

Есть родственные функции `CURDATE()` (только дата, без времени) и `CURTIME()` (только время, без даты). `NOW()` часто используется для расчёта возраста записи «на данный момент» — например, сколько дней прошло с момента регистрации клиента.

### YEAR, MONTH, DAY: извлечение частей даты

Функции `YEAR(дата)`, `MONTH(дата)` и `DAY(дата)` извлекают из значения типа `DATE` или `DATETIME` соответствующую числовую часть:

```sql
SELECT registered_at, YEAR(registered_at) AS reg_year, MONTH(registered_at) AS reg_month
FROM customers;
```

Для `registered_at = '2023-11-08'` этот запрос вернёт `reg_year = 2023` и `reg_month = 11`. Эти функции пригодны и в `WHERE` — например, найти клиентов, зарегистрировавшихся в 2023 году, независимо от месяца и дня:

```sql
SELECT name
FROM customers
WHERE YEAR(registered_at) = 2023;
```

### EXTRACT: универсальный способ извлечь часть даты

`EXTRACT(часть FROM дата)` — более универсальный синтаксис, решающий ту же задачу, что и `YEAR`/`MONTH`/`DAY`, но с единым синтаксисом для большего числа возможных частей, включая составные — например, «год и месяц вместе»:

```sql
SELECT EXTRACT(YEAR FROM registered_at) AS reg_year,
       EXTRACT(MONTH FROM registered_at) AS reg_month,
       EXTRACT(YEAR_MONTH FROM registered_at) AS reg_year_month
FROM customers;
```

`EXTRACT(YEAR_MONTH FROM ...)` возвращает год и месяц, склеенные в одно число (например, `202311` для ноября 2023 года) — удобно для группировки данных по месяцам без промежуточного текстового форматирования (к самой группировке, `GROUP BY`, мы вернёмся в отдельном уроке чуть позже).

### DATE_FORMAT: форматирование даты в текст по шаблону

Хранимая дата типа `DATE`/`DATETIME` — не текст, а специальный внутренний формат данных, и её отображение по умолчанию (например, `2024-03-15`) не всегда соответствует желаемому виду отчёта. Функция `DATE_FORMAT(дата, шаблон)` преобразует дату в текст по заданному шаблону из специальных управляющих последовательностей, начинающихся с `%`:

```sql
SELECT DATE_FORMAT(registered_at, '%d.%m.%Y') AS reg_date_ru
FROM customers;
-- для '2023-11-08' вернёт '08.11.2023'
```

Самые часто используемые управляющие последовательности: `%Y` — год из четырёх цифр, `%m` — месяц из двух цифр (с ведущим нулём), `%d` — день месяца из двух цифр, `%H`/`%i`/`%s` — часы/минуты/секунды. Один из самых практически ценных шаблонов, часто встречающийся в аналитике, — `'%Y-%m'`, дающий «месячный ключ» вида `'2024-03'`, удобный для последующей группировки данных по месяцам без потери сортируемости (в отличие, например, от `'март 2024'`, который не сортируется в хронологическом порядке простым текстовым сравнением):

```sql
SELECT id, DATE_FORMAT(created_at, '%Y-%m') AS order_month
FROM orders;
```

### DATE_ADD: смещение даты на интервал

Функция `DATE_ADD(дата, INTERVAL число единица)` добавляет к дате указанный интервал времени — дни, месяцы, годы и так далее:

```sql
SELECT DATE_ADD('2024-03-15', INTERVAL 10 DAY) AS plus_ten_days;
-- вернёт '2024-03-25'
```

```sql
SELECT DATE_ADD(registered_at, INTERVAL 1 YEAR) AS first_anniversary
FROM customers;
```

Для вычитания интервала есть родственная функция `DATE_SUB`, либо можно передать в `DATE_ADD` отрицательное число:

```sql
SELECT DATE_SUB('2024-03-15', INTERVAL 1 MONTH) AS minus_one_month;
-- вернёт '2024-02-15'
```

Типичное практическое применение — найти заказы, оформленные за последние 30 дней от текущего момента:

```sql
SELECT id, created_at
FROM orders
WHERE created_at >= DATE_SUB(NOW(), INTERVAL 30 DAY);
```

### DATEDIFF и TIMESTAMPDIFF: разница между двумя датами

Функция `DATEDIFF(дата1, дата2)` возвращает разницу между двумя датами **в целых днях** (время суток при этом не учитывается, даже если исходные значения — `DATETIME`):

```sql
SELECT DATEDIFF('2024-03-15', '2024-03-01') AS days_between;
-- вернёт 14
```

Практический пример — вычислить, сколько дней клиент уже с нами, от момента регистрации до текущего дня:

```sql
SELECT name, DATEDIFF(CURDATE(), registered_at) AS days_since_registration
FROM customers;
```

Если разница нужна не только в днях, а в других единицах — часах, минутах, месяцах, — на помощь приходит более гибкая функция `TIMESTAMPDIFF(единица, дата1, дата2)`, где первым параметром указывается желаемая единица измерения:

```sql
SELECT TIMESTAMPDIFF(HOUR, '2024-03-15 08:00:00', '2024-03-15 20:30:00') AS hours_between;
-- вернёт 12 (дробная часть отбрасывается: реально между значениями 12 часов 30 минут)
```

```sql
SELECT name, TIMESTAMPDIFF(MONTH, registered_at, CURDATE()) AS months_with_us
FROM customers;
```

Обратите внимание на порядок аргументов у обеих функций: `DATEDIFF(a, b)` вычисляет `a - b` (то есть «сколько дней прошло от b до a»), а `TIMESTAMPDIFF(unit, a, b)` вычисляет `b - a` — порядок дат в этих двух функциях **разный** и его легко перепутать, что даст правильное число, но с обратным знаком.

### Резюме

- `ROUND(число, [знаков])` округляет по обычным правилам (в том числе до десятков/сотен через отрицательное число знаков); `FLOOR` всегда округляет вниз, `CEILING`/`CEIL` — всегда вверх; выбор между ними зависит от смысла задачи, а не только от желаемой точности.
- `ABS(число)` возвращает значение без знака — модуль числа.
- `NOW()` возвращает текущую дату и время; `CURDATE()`/`CURTIME()` — только дату/только время.
- `YEAR`/`MONTH`/`DAY` извлекают отдельные числовые части даты; `EXTRACT(часть FROM дата)` — универсальный синтаксис для тех же и составных частей (например, `YEAR_MONTH`).
- `DATE_FORMAT(дата, шаблон)` превращает дату в текст по шаблону из управляющих последовательностей (`%Y`, `%m`, `%d`, …); шаблон `'%Y-%m'` даёт хронологически сортируемый «месячный ключ».
- `DATE_ADD`/`DATE_SUB` смещают дату на заданный интервал (`INTERVAL число единица`).
- `DATEDIFF(a, b)` — разница в целых днях (`a - b`); `TIMESTAMPDIFF(единица, a, b)` — разница в произвольной единице (`b - a`, порядок аргументов обратный по сравнению с `DATEDIFF`).
